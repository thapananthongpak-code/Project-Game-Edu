# แผนแก้รอบ 16: กรอบสีขาวรอบตัวตอนโจมตี

สถานะ: **ทำแล้ว** (ผู้ใช้ยืนยัน) (เขียนเมื่อ 25 ต.ค. 2569 จากโค้ดที่ commit `0be23dc`)

## อาการ

ในด่านต่อสู้ ตาที่การ์เดียนตีไคจู หรือไคจูตีการ์เดียน มีกรอบสี่เหลี่ยมสีขาวขึ้นรอบตัวฝ่ายที่โดนตี ไม่ควรมี

## สาเหตุ (ตรวจโค้ดแล้ว)

1. **เอฟเฟกต์วาบขาวตอนโดนตี (`.battle-flash` ที่เพิ่มในรอบ 14)** เป็นสี่เหลี่ยมพื้นขาวเต็มกรอบของตัวละคร (`inset: 0; background: #fff`) ไม่ได้วาบเฉพาะตัวละคร จึงเห็นเป็นกล่องขาวทั้งกรอบ
2. **กรอบขาวค้างตั้งแต่ต้นตา ไม่ใช่แค่ตอนโดนตี:** แอนิเมชันตั้ง `animation-fill-mode: both` คู่กับเวลาหน่วง (`animation-delay` = จังหวะที่โดนตี) ระหว่างรอถึงจังหวะ เบราว์เซอร์ใช้ค่าเฟรมแรก (ทึบ 85%) ทันที กล่องขาวจึงขึ้นตั้งแต่ตอบคำถามจนโดนตีจริงแล้วจางไปอีก 0.25 วินาที
3. **ปัญหาแบบเดียวกันที่เจอเพิ่ม:** เศษเกราะแตก (`.battle-shards`) ใช้ `both` และเฟรมแรกทึบ ช่วงก่อนเกราะแตก จึงมีสี่เหลี่ยมเล็กสีเทา 7 ชิ้นค้างกลางตัวไคจู
4. ตรวจเอฟเฟกต์อื่นที่ใช้ `both` แล้ว (ตัวเลขลอย ป้ายชื่อท่า ภาพกลายร่าง ภาพเอฟเฟกต์อาวุธ ภาพท่าโจมตีของไคจู): เฟรมแรกโปร่งใสหรือเท่ากับค่าปกติ ไม่มีปัญหา

## วิธีแก้

- **เอากล่องวาบขาวออก** แล้วให้ "วาบ" ที่ตัวละครแทน: ใช้ตัวกรองความสว่างกับภาพตัวละครเอง (เฉพาะพิกเซลของตัวละคร ไม่มีกรอบ) ห่อรอบภาพหุ่นและภาพไคจู สีหุ่นที่ย้อมไว้ยังอยู่ (ตัวกรองซ้อนกันได้)
- เปลี่ยนเวลาเติมของแอนิเมชันเป็นแบบไม่แสดงก่อนถึงจังหวะ (`forwards` หรือไม่เติม) ทั้งวาบตอนโดนตีและเศษเกราะ
- คงเอฟเฟกต์อื่นไว้เหมือนเดิม: ท่าถอยเมื่อโดนตี ตัวเลขดาเมจ ภาพเอฟเฟกต์อาวุธ ไอคอนสถานะเหนือหัว
- ผู้ใช้ที่ตั้งค่าลดการเคลื่อนไหว: ไม่มีวาบ (เหมือนเดิม)

## การทดสอบ

- **ตรวจด้วยภาพจริง:** ถ่ายภาพฉากต่อสู้ระหว่างตาที่โดนตีหลายจังหวะ (ก่อนโดนตี ตอนโดนตี หลังโดนตี) ทั้งฝั่งการ์เดียนและไคจู เปิดดูว่าไม่มีกรอบขาวและไม่มีสี่เหลี่ยมค้าง
- **e2e:** ระหว่างตาที่มีการโจมตี ไม่มีองค์ประกอบพื้นทึบสีขาวทับกรอบของตัวละคร และเศษเกราะโปร่งใสก่อนเกราะแตก ชุด main normal hard ต้องผ่าน และผ่านการตรวจการเข้าถึง
